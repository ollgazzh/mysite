# Сайт-визитка Ольги

Это мой личный интерактивный сайт-визитка, написанный с нуля на чистом HTML, CSS и JavaScript.

## Что здесь есть:
- Анимации при клике на буквы имени: при нажатии на буквы «О, л, ь, г, а» запускаются падающие слова (ООП, алгоритмы и т.д.), а на букве «г» рисуется граф в виде сердечка на Canvas.
- Интерактивное меню: плавное переключение между разделами «Обо мне», «Мои увлечения» и «Мои желания».
- Галерея путешествий: адаптивная сетка с фотографиями городов, которые я хочу посетить.
- Приятный дизайн: теплая желто-коричневая цветовая гамма, плавные анимации фона и адаптивная верстка.

## Технологии:
- HTML5
- CSS3 (Flexbox, Grid, Keyframes-анимации)
- JavaScript (Vanilla JS, Canvas API)

## Структура проекта:
- `index.html` — разметка страницы.
- `style.css` — все стили и анимации.
- `script.js` — логика переключения блоков и анимации букв.
- `images/` — папка с фотографиями для галереи.
